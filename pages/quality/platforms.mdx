# Platform-specific

## Test matrix

Test every P0 case on each of these at least once per release.

| Platform | Versions to cover |
| --- | --- |
| Web | Latest Chrome, Edge, Firefox, Safari |
| Desktop | Windows 10 & 11, macOS latest two, Ubuntu LTS |
| iOS | Latest two major versions, one small iPhone, one iPad |
| Android | Android 10+, Samsung, Pixel, one Xiaomi or Huawei |
