## Who gets notified about thread replies

A thread reply does **not** notify everyone in the room. Only thread followers get notified.

A user follows a thread when they:

- **Started it** — they wrote the root message.
- **Replied in it** — any reply makes them a follower.
- **Are @mentioned** in the root or any reply.
- **Follow it explicitly** — they tap "Follow thread".

Everyone else sees only the reply count on the root message.

Extra rules:

- **Unfollow wins.** A user who unfollows stops getting notified, even if they started or replied. Only a new @mention makes them follow again.
- **1:1 DMs.** Every thread reply notifies the other person.
- **Room level still applies.** Following a thread in a muted or mentions-only room does not override that room's level.

### How other apps do it

| App | Started it | @mentioned | Replied | Manual follow | Notes |
| --- | --- | --- | --- | --- | --- |
| Slack | ✅ | ✅ | ✅ | ✅ Follow / Unfollow | In 1:1 DMs, every thread reply notifies |
| Teams | ✅ | ✅ | ✅ | ✅ | A channel setting can follow every new thread |
| Discord | ✅ | ⚠️ developer docs only | ✅ posting joins you | ✅ Join Thread | Joined threads default to "All messages", ignoring the server's mentions-only setting. Users dislike this |
| Element | ✅ | ✅ normal mention rules | ✅ | ⚠️ no clear follow button | Matrix counts "participated" as wrote the root or replied |
| Telegram | — | — | — | — | No real threads. Replies to your comments go to a "Replies" chat |
| WhatsApp | — | — | — | — | No threads |
