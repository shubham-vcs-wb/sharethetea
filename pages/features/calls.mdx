# Voice & Video Calls

Calls are where users notice bugs fastest. A dropped call is worse than a dropped message.

## Call feature glossary

Plain-English meaning of each feature, so you know what to build and test.

| Feature | What it means |
| --- | --- |
| 1:1 call | Voice or video between two people |
| Group call | Three or more people in one call |
| Escalate 1:1 to group | Add a third person to a running 1:1 call |
| Add / invite to call | Ring someone new into an active call |
| Remove (kick) from call | Host drops a participant |
| Mute others / mute all | Host mutes someone else's mic |
| Hold / resume | Pause a call (both sides hear silence or hold music) without hanging up |
| Call waiting | A second call rings while you are already on a call |
| Answer and hold / answer and end | Choices when a second call arrives |
| Merge calls | Join a held call and the active call into one group call |
| Swap calls | Switch between a held call and an active call |
| Blind (cold) transfer | Send the call to someone else without talking to them first |
| Attended (warm) transfer / consult | Talk to the target first, then hand the call over |
| Forward / divert | Auto-send incoming calls elsewhere (always, if busy, if no answer) |
| Call park / pickup | Park a call in a slot; anyone picks it up from another device |
| Delegation / boss-assistant | Assistant answers calls on behalf of a manager |
| Call queues / hunt groups | Ring a team; first free agent answers |
| Voicemail | Leave and play back recorded messages, with transcription |
| PSTN / dial-pad | Call real phone numbers; send DTMF tones for IVR menus |
| Device handoff | Move a live call from laptop to phone without dropping |
| Ringing on all devices | Every logged-in device rings; answering on one stops the rest |
| Call history / missed calls | Log of calls with duration and status |
| Recording & transcription | Save the call and its text |
| Noise suppression / background blur | Clean up audio and video |
| Raise hand | Ask to speak in a group call |
| Spotlight / pin video | Keep one person large on screen |
| Picture-in-picture | Small floating call window while using the rest of the app |
| Walkie-talkie / push-to-talk | Hold a button to speak |
| Voice channels (drop-in) | Always-open audio room you join and leave freely (Discord, Slack Huddles) |
