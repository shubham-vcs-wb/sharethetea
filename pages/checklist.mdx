# Release Checklist

Go through this before every release. Every box should be ticked or have a written reason.

## Must pass (P0)

- [ ] All P0 test cases on every feature page pass
- [ ] Send / receive / edit / delete works in DM, group and encrypted room
- [ ] 1:1 and group call connect on web, desktop, iOS and Android
- [ ] Calls work behind a strict firewall (TURN on 443)
- [ ] Push notifications arrive with app killed on iOS and Android
- [ ] New-device login restores encrypted history
- [ ] Removed / banned users lose access immediately
- [ ] No plaintext from encrypted rooms on server or in push
- [ ] Offline sending recovers with order kept
- [ ] No new crash in crash reporting dashboards

## Should pass (P1)

- [ ] Performance targets met (see Performance page)
- [ ] Accessibility scan has no critical issues
- [ ] Translations complete for supported languages
- [ ] Admin actions show in audit log
- [ ] Upgrade from previous version keeps data and sessions
